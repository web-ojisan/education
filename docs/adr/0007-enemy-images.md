# 0007 敵キャラの絵の持ち方

- 状態：採用
- 日付：2026-11-17

## 状況

敵の絵を、コードで描いた簡単な図形から、画像生成AIなどで作った凝った絵に置き換えたい。敵の種類も増やす。絵がそろうまでの間もゲームは動かしたい。

## 決定

- **絵は敵ごとに4枚の静止画で持つ。** 置き場所は `public/img/enemies/<フォルダ名>/`。
  - `idle.webp`（構え）／`hit.webp`（殴られ顔）／`ko.webp`（KO）／`attack.webp`（攻撃）
  - 背景が透明な正方形のWebP（640px、1枚50KB前後）。キャラは下端中央に合わせる。
  - 元のシートは `art/raw/` に残し、`tools/cut-enemy-sheet.py` で切り分ける。
- **敵の一覧（コード内の `ENEMIES`）に `img: 'フォルダ名'` と書いた敵だけが画像を使う。** 書いていない敵は、コードで描いた仮の絵で動く。画像が読めなかった場合も仮の絵に戻す。
- **動きはコードで付ける。** 息づかい、のけぞり、吹っ飛び、画面の揺れは、静止画にそのまま掛ける。
- **攻撃の絵がある敵**は、誤答のときにその絵へ切り替え、敵全体を手前へ大きく寄せる。攻撃の絵がない敵は、拳の図形が飛んでくる。
- **攻撃の文字と音は、敵ごとに変えられる。**
  - `atkWords`：当たった時に火花の中に出る文字。ヒグマは「ザシュッ」、ゾンビは「ガブッ」、ドラゴンは「ボォォ」など。書かなければパンチの文字（ドカッ、ボコッ…）。
  - `atk: 'fire'`：打撃音のかわりに炎の音を鳴らし、赤い光のかわりに、下から炎が画面をおおって火の粉が舞い上がる。ドラゴンで使用。
- `size`：絵の中で小さく描かれたキャラクターを大きく見せる倍率。
- 設定画面の「自分の絵に差し替える」で選んだ絵は、すべての敵より優先して使う（その場かぎりで、保存はされない）。
- 絵の作り方と画像生成AIへの指示文は [`docs/enemy-art.md`](../enemy-art.md) にまとめる。

## 理由

- 画像生成は絵の密度に強く、コードは状態に合わせた動きに強い。動画やコマ送りにすると、背景の透過やゲームの状態との同期が難しくなる。
- 一覧に書いた敵だけ画像を読むことで、存在しないファイルを探しに行く無駄な通信が起きない。

## 影響・注意

- 既存のキャラクターや実在の人物に似せた絵は使わない（公開サイトのため）。
