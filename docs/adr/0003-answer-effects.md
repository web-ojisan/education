# 0003 正解・誤答の判定と演出

- 状態：採用
- 日付：2026-11-17

## 状況

速く正確に答えることを気持ちよく感じさせ、まちがいは罰ではなく演出として伝えたい。ダメージやGAME OVERは不要。

## 決定

答えるまでの時間が、設定の「暗記とみなす速さ」（初期値2秒、1〜5秒で調整可）より速いかどうかで4通りに分ける。

| | 正解 | 誤答 |
|---|---|---|
| **速い** | ワン・ツー（ジャブ → 0.12秒後にストレート。大きな火花・画面の光・ヒットストップ）。判定は「暗記！」（じゅんばんでは「はやい！」） | 敵がこちらのパンチをかわし（「スカッ」）、カウンターを打ってくる。判定は「カウンター！」 |
| **遅い** | 軽いジャブ。判定は「考えた」 | 敵がそのまま殴ってくる。判定は「ちがうよ」 |

- **打撃の音は3種類。** ブラウザの中で合成して鳴らす（音声ファイルは使わない）。
  - ジャブ：速くて切れのある「バシッ」（約0.07秒）。短いが、当たった手ごたえの中低音も入れる。遅い正解の1発と、ワン・ツーの1発目。
  - ストレート：重くてゴツい「ドゴッ」（約0.25秒）。ワン・ツーの2発目。
  - KO：必殺技の音。短い「ため」→ 大きな爆発 → やまびこの付いた長いひびき（約1.5秒）。いちばん大きい。
- **KOの一撃は、速く答えた時はワン・ツーの2発目、遅い時や最後をまちがえた時は単発またはワン・ツーの締めとして出す。**
- **誤答の判定は1文字ごと。** 打った数字が正しい答えの先頭と合わなくなった時点で誤答とする。
- **誤答したら打ち直しはさせない。** 殴られ、正しい答えを赤く表示し、少し待って（約0.8〜1秒）次の問題へ進む。
- **まちがえた問題は、その敵の最後にもう一度出す（1回だけ）。** 「もういちど！」と付けて出す。正解すれば、自分の手でその敵をたおせる。2回目もまちがえたら、答えを見せて、とどめの一撃でKOへ進む。
  - その場で正解するまで進めない形にしなかったのは、詰まった感じになり、見えている答えを写すだけになるため。ほかの問題を解いてから戻る方が、流れが止まらず、少し間をおいて思い出すので覚えやすい。
  - まちがえたまま流れていくと「自分で直したい」気持ちが残る、という子供の声を受けて入れた。
  - 集団の敵では、残った敵が「もう一度出る問題」に対応する。正解すれば、その分を自分でたおせる。
  - おんどくでも同じ。言いまちがえた式が最後にもう一度出る。「なにも出さない」設定でも、もう一度の時は式を出す。
  - 殴られた回数は、まちがえるたびに数える。じゅんばん合格・ベストタイム・パーフェクトは、1回でもまちがえたら付かない。
- **殴られてもダメージやGAME OVERはない。** 「ミスした回数＝殴られた回数」として数えるだけ（→ 0005）。
- **速さでダメージ量は変わらない。** 変わるのは演出の強さだけ。
- **敵の最後の問題は必ずKO。** 最後が正解ならその一発で、誤答なら殴られた後のとどめの一発で、敵は画面の奥へ飛んで星になる。
- **パーフェクト：その敵の全問を、速く正解したとき（じゅんばんでも、ランダム・弱点でも、穴あきでも同じ）は、最後のKOを特別に派手にする。**
  - 一撃：火花を3回重ね、止める時間を長くし、揺れを強くする。敵は大きくなってから、いつもの2倍回転して飛んでいく。
  - 星になった後：「K.O.!」の代わりに光る「PERFECT!」を長め（1.7秒）に出す。ファンファーレを鳴らし、紙ふぶきを降らせ、星の花火を6つ上げ、背景の集中線を回す。
  - 1問でも遅い・まちがいがあれば、ふつうのKOになる。
  - サイクル結果の画面に「パーフェクト 3／9体」のように数を出す（1体以上あるときだけ）。記録としては保存しない。
- 敵はふだん両拳を構えている。殴られるとガードが開き、KOで下がる。殴ってくるときは構えた拳が画面いっぱいに飛んでくる。
- 「動きを減らす」設定の端末では、揺れ・光・拡大を弱める。

## 理由

- 速い誤答は「あてずっぽうで打った」ことが多い。かわされてカウンターという演出で、落ち着いて答える方向へ促す。
- 打ち直しをなくすとテンポが保たれる。正しい答えは表示するので、学習の機会は残る。

## 影響・注意

- 上級者・地獄は答えが3桁になるため、2秒以内は大人でも厳しい。必要なら「暗記とみなす速さ」をゆるめる。
- 30秒を超えた回答と、途中でタブを離れた回答は記録しない（演出は出る）。
