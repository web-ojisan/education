# 0005 記録・ワースト・保存データ

- 状態：採用
- 日付：2026-11-17

## 状況

上達を確かめるために、問題ごとの速さと、まちがえた回数を残したい。できるようになったら消して最初から挑戦する、という使い方を想定する。

## 決定

- **遊ぶ人は5人まで**（→ 0014 で3人から変更）。 記録・設定は人ごとに分ける。開始時は必ず名前を選ぶ。
- **マスごとの記録**：挑戦回数、まちがい回数、直近5回の（時間・正誤）。状態は直近3回から決める。
  - 暗記：すべて正解で、平均が「暗記とみなす速さ」より速い
  - 考えてる：すべて正解だが遅い
  - まちがえた：直近3回に誤答がある
  - まだ：出題されていない
- **殴られた回数**：1サイクルの間、誤答1回につき1回と数える。サイクルが終わると結果画面に、今回の回数とこれまでのワーストを並べて出す。「つぎのサイクルへ」で0に戻る。結果画面には「名前えらびにもどる」もあり、設定を見直してから遊び直せる。
- **ワースト記録**：1サイクルで殴られた回数の最大値。人ごとに保存し、設定と記録の画面にも表示する。
- **サイクルの途中でやめた場合**（交代・再読み込み・設定変更によるやり直し）は、その回の回数を記録しない。
- **「記録を消す」**：いま遊んでいる人の、マスごとの記録（ふつう・穴あきの両方）とワーストを消す。解放済みのモードと設定は残す。完全に最初からにしたい場合は、名前選択の画面でその人を消して作り直す。

## 保存データ

ブラウザの `localStorage` に、キー `kuku-punch-v2` で保存する。サーバーには送らない。

```
{
  v: 保存データの版数（いまは 3。→ 0010）,
  last: 最後に遊んだ人のid,
  profiles: [{
    id, name,
    adult:     おとなかどうか（→ 0014）,
    inbox:     るすの間の知らせ [{ from: おとなの名前, a: 段, level: モード, kind: 'win'|'lose'|'new' }]（見たら消える。→ 0014）,
    hc:        おとなのハンデの進み具合 { おとなのid: { モード番号: { 段: 勝った回数 } } }（こどもの側に持つ。→ 0014）,
    th:        暗記とみなす速さ（ミリ秒、1000〜5000）,
    dans:      出題する段の配列,
    type:      'seq'（じゅんばん）| 'rand'（ランダム）| 'weak'（弱点）,
    level:     いまのモード 0〜2,
    unlocked:  解放済みのモード 0〜2,
    worst:     1サイクルで殴られた回数のワースト（未記録は null）,
    lock:      設定のロックのパスワード（6桁の数字の文字列。ロックしていなければ null）,
    form:      問題の形 'norm'（ふつう）| 'hole'（穴あき）| 'mix'（まぜる）,
    holes:     穴あき問題の記録。形は cells と同じ（→ 0008）,
    seq:       じゅんばんの段ごとの成績 { モード番号: { 段: { pass: 合格したか, best: ベストタイム（ミリ秒）, n: 通した回数 } } }（→ 0010）,
    cells:     ばらばらに出た問題の記録（→ 0010） { '3x7': { n: 挑戦回数, miss: まちがい回数, log: [[ミリ秒, 正解なら1], …最大5件] } }
  }]
}
```

## 理由

- ワーストを「記録を消す」で一緒に消すのは、上達した後に最初から挑戦し直せるようにするため。
- 解放済みのモードを残すのは、記録を消しただけで遊べるモードが減ると、やり直す気持ちをそぐため。

## 影響・注意

- 記録はそのブラウザの中だけにあり、端末やブラウザを変えると引き継がれない。ブラウザのデータを消すと記録も消える。
- 壊れた保存データを読んでも動くよう、読み込み時に値を点検して、おかしいものは初期値に戻す。
