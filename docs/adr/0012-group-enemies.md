# 0012 集団の敵（1問で1体たおす）

- 状態：試作（しんじんボクサーの絵を仮に使っている。本番の絵はゾンビを予定）
- 日付：2026-11-18

## 状況

「わらわらいるゾンビ集団」のような敵を出したい。敵ひとりにつき9問（上級者14問、地獄18問）というルールがあるので、「問題の数だけ敵が並び、1問正解するごとに1体たおす」形にすると、ルールと見た目がそのまま合う。

## 決定

- **敵の一覧（`ENEMIES`）で `group: true` を付けた敵は、集団として出す。** 絵は単体の敵と同じ4枚（構え・やられ顔・KO・攻撃）を使い、問題の数だけ並べる。
- **並べ方**：前の列から5体ずつ（18体のときは6体ずつ）。後ろの列ほど小さく、暗くする。同じ絵でも、左右の向きと動きのタイミングをずらして、別々の敵に見せる。
- **正解**：前の列のまんなかの1体をたおす。
  - 遅い正解：ジャブ1発で、横へ転がって消える。
  - 速い正解：ワン・ツーで、奥へ飛んで星になる。
  - たおすと、残りの敵が前へつめて並び直す。
- **誤答**：ねらっていた1体が攻撃の絵に変わり、大きく手前に迫ってくる。その1体はたおれず、残る。
- **最後の問題**：残っている全員（まちがえた分）を、とどめの一撃でまとめて吹っ飛ばす。そのあとの「K.O.!」「PERFECT!」、成績の表示、次の敵への流れは、単体の敵と同じ。
- **残っている数が、そのまま「あと何問」の目印になる。**
- KOの数は、集団ぜんたいで1と数える。

## 理由

- 絵を増やさずに、1枚のシートから大群を作れる。
- 体力メーターをなくした（→ 0002）代わりに、進み具合が見えるようになる。
- 正解のたびに1体吹っ飛ぶので、1問ごとの手ごたえが単体の敵より大きい。

## 影響・注意

- よこ持ちスマホではステージが低いので、1体は高さ110pxほどになる。
- 設定画面の「自分の絵に差し替える」は、集団の敵には使われない。
- 個性を出したい場合は、シートを2〜3種類用意して混ぜる拡張が考えられる（未実装）。
