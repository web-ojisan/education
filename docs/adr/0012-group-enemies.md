# 0012 集団の敵（1問で1体たおす）

- 状態：採用（2番目の敵「ゾンビ軍団」で使用）
- 日付：2026-11-18

## 状況

「わらわらいるゾンビ集団」のような敵を出したい。敵ひとりにつき9問（上級者14問、地獄18問）というルールがあるので、「問題の数だけ敵が並び、1問正解するごとに1体たおす」形にすると、ルールと見た目がそのまま合う。

## 決定

- **敵の一覧（`ENEMIES`）で `group: true` を付けた敵は、集団として出す。** 絵は単体の敵と同じ4枚（構え・やられ顔・KO・攻撃）を使う。
- **絵は何種類か混ぜられる。** `img: ['zombie', 'zombie-f', 'zombie-fat']` のように複数書くと、同じ数ずつ割りふって、並びをまぜる。同じ顔ばかりの「クローン軍団」に見えるのを防ぐ。
- **人数は問題の数の3倍。** ふつう27体、上級者42体、地獄54体。**正解1回で3体たおす。**（1問1体の9体では、数が少なくて集団に見えなかった。）
- **並べ方：手前ほど大きく、迫ってくるように見せる。**
  - 手前の列はいちばん大きく、腰から下は画面の下に切れる。奥の列ほど小さく、高い位置に、暗く描く。
  - 各列は画面の幅いっぱいに並べ、体が重なり合うようにつめる。並べられる数は画面の大きさから決める。
  - 同じ絵でも、左右の向き、動きのタイミング、位置、大きさを1体ずつ少しずらす。
- **正解**：手前の列のまんなかの3体をたおす。
  - 遅い正解：ジャブ1発で、横へ転がって消える。
  - 速い正解：ワン・ツーで、奥へ飛んで星になる。
  - たおすと、後ろの敵が前へ出て大きくなる（＝押し寄せてくる）。
- **誤答**：ねらっていた1体が攻撃の絵に変わり、大きく手前に迫ってくる。たおれず、残る。
- **最後の問題**：残っている全員（まちがえた分）を、とどめの一撃でまとめて吹っ飛ばす。そのあとの「K.O.!」「PERFECT!」、成績の表示、次の敵への流れは、単体の敵と同じ。
- **残っている数が、進み具合の目印になる。**
- KOの数は、集団ぜんたいで1と数える。

## 理由

- 絵を増やさずに、1枚のシートから大群を作れる。
- 体力メーターをなくした（→ 0002）代わりに、進み具合が見えるようになる。
- 正解のたびに1体吹っ飛ぶので、1問ごとの手ごたえが単体の敵より大きい。

## 影響・注意

- よこ持ちスマホではステージが低いので、手前の列でも顔とグローブが見える程度の大きさになる。タブレットでは手前の列がかなり大きく出る。
- 設定画面の「自分の絵に差し替える」は、集団の敵には使われない。
