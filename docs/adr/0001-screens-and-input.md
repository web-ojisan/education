# 0001 画面構成と数字入力

- 状態：採用
- 日付：2026-11-17

## 状況

遊ぶのは子供で、スマホやタブレットを横持ちにして使う想定。答えるまでの速さを測るゲームなので、数字を探す・指を動かす時間は短くしたい。また、ゲーム中に記録表が見えていると画面が窮屈になる。

## 決定

- **画面は2つに分ける。** ゲーム画面と「設定と記録」画面。後者は名前ボタンの隣の歯車ボタンから開く。
- **ゲーム画面は上から「敵 → 計算式 → 数字ボタン」の縦積みにする。** 敵と計算式を左右に分けない。
- **横持ちでは数字ボタンを下端に1列で並べる。** 並びは `1 2 3 4 5 | 6 7 8 9 0`。5と6の間に隙間を空け、左手が1〜5、右手が6〜0を担当する。スクロールなしで1画面に収める。
- **縦持ちとパソコンでは5列×2段にする。** 並び順は横持ちと同じ。パソコンではキーボードの数字キーでも入力できる。
- **高さが足りない横持ちスマホ（高さ520px以下）では、判定の文字を計算式の右に置く。**
- **ゲーム画面とダイアログでは、ダブルタップと2本指での拡大を止める。** 子供が連打したり、両手で同時に押したりしても画面が拡大しないようにする。文字の選択と長押しメニューも出さない。設定と記録の画面は、文字を大きくして読めるよう2本指の拡大を残す。
- **数字ボタンは、指がふれた瞬間に入力する。** 指を離した時（クリック）を待たない。指が少しすべった時や、両手の指が同時にふれている時に入力が落ちるのを防ぐ。
- **ボタンのすき間をさわった時は、いちばん近いボタンを押したことにする。**
- **押したボタンは一瞬色を変える。** 入力が受け付けられたことが見て分かるようにする。
- **問題が出た直後の0.18秒は入力を受けない。** 前の問題で押しすぎた分が、次の問題のまちがいになるのを防ぐ。人が問題を見て答えるにはそれ以上かかるので、ふつうの回答には影響しない。キーボードの押しっぱなしによる連続入力も受けない。
- 設定画面を開いている間はゲームを止める。出題にかかわる設定（ゲームタイプ・モード・出題する段）を変えて戻ると、最初の敵からやり直す。

## 理由

- 横持ちスマホは高さが360px前後しかなく、テンキー（3列×4段）は入らない。1列なら高さを敵と計算式に回せる。
- 左右の手の担当が決まると、慣れたときに数字を探さずに打てる。
- 敵と計算式が左右に分かれると視線が横に飛ぶ。縦積みなら「敵を見る → 式を読む → 打つ」が上から下へ流れる。

## 影響・注意

- タブレットを両手で持つと、中央の4〜7に親指が届きにくい可能性がある。実機で確認し、届きにくければタブレットだけ左右の端に寄せた配置を検討する。
- スマホのブラウザではアドレスバーの出方によって下端のボタンが隠れる可能性がある。
- 横持ちスマホでは敵がやや小さくなる。
