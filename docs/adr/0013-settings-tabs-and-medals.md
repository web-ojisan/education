# 0013 設定画面を3つのタブに分け、記録の表にメダルを付ける

- 状態：採用（タブは 0014 で「くらべる」が加わり4つに。0001 の「設定と記録」画面の構成、0006 のロックの範囲、0010 の「段ごとの合格」の見せ方を置き換える）
- 日付：2026-11-18

## 状況

設定と記録が1つの長い画面に並び、よく変えるもの（段・出し方）と、めったに触らないもの（ロック・絵の差し替え）が混ざっていた。スマホでは、記録を見るのに設定を全部スクロールで通り過ぎる必要があった。また「段ごとの合格」の一覧と九九の表が、同じ「段」を2回並べていて、縦に長かった。ロック中は子供が記録も見られなかった。

## 決定

### 3つのタブ

| タブ | 入れるもの | 使う人・頻度 |
|---|---|---|
| あそびかた | 出題する段、ゲームタイプ、問題の形、モード | 親子・よく使う |
| きろく | 九九の表（ふつう／穴あき）、にがてな九九、ワースト | 親子・見るだけ |
| おうちの人 | 暗記とみなす速さ、設定のロック、記録を消す、敵の絵の差し替え | 親・たまに |

- **「あそびかた」は考える順に並べる。** ① どの段を → ② どの順で → ③ どんな形で → ④ むずかしさ。
- **いちばん上に、いまの設定のまとめを出す。** 「じゅんばん｜2・3の段 → 敵2人・18問で1サイクル」。設定を変えると、その場で変わる。
- 段には「ぜんぶえらぶ」「ぜんぶはずす」（いちばん小さい段だけ残る）を付ける。
- 説明文は、選んでいる項目の1〜2行だけにする。

### ロックの範囲

- **ロック中でも「きろく」はパスワードなしで見られる。** ロック中に画面を開くと「きろく」から始まる。
- **「あそびかた」と「おうちの人」を開く時にパスワードを求める。** 一度通せば、画面を閉じるまではどちらも開ける。
- ロックを設定した直後は、そのまま続けて使える。

### 記録の表のメダル

- **「段ごとの合格」の一覧をなくし、九九の表の各行に埋め込む。**
- **行の左端（段の数字）をメダルにする。**
  - 銀の輪：じゅんばん合格
  - 金：その段のマスがぜんぶ暗記
  - 金に星：両方
- **行の右端に、じゅんばんのベストタイム（秒）を1列足す。**
- 「暗記 7/9」の数字は表に出さない（マスの色で分かる）。メダルを押すと、下の欄に「3の段：暗記 7/9、じゅんばん合格、ベスト 9.8秒、通した回数」を出す。
- 穴あきの表では、じゅんばんの成績は付かないので、金メダルだけを出し、ベストタイムの列は出さない。

## 理由

- 性質の違うものを分けると、子供が触る「あそびかた」が短くなり、1画面に収まる。
- 記録は見せて困るものではなく、子供のやる気にもなるので、ロックの外に出す。
- 表とメダルを1つにまとめると、「どの段がどこまで進んだか」が1か所で分かり、画面も短くなる。

## 影響・注意

- スマホの縦持ちでは表の幅が狭いので、足す列はベストタイムの1列だけにしている。
- 広い画面では、表が大きくなりすぎないよう幅を600pxまでにしている。
