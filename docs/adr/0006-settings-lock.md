# 0006 設定のロック

- 状態：採用（ロックの範囲は 0013 で変更：ロック中でも「きろく」は見られる）
- 日付：2026-11-17

## 状況

親がゲームタイプを「弱点」に固定するなど、子供に設定を変えさせたくない場面がある。

## 決定

- **設定画面に「設定のロック」を置く。** 遊ぶ人ごとに設定する。
- **ONにする手順**
  1. 注意を表示する：「パスワードを忘れると元に戻せない。その場合は名前選びの画面の『消す』で、名前・記録・設定をまとめて消すしかない」。OKを押すまで先へ進まない（やめることもできる）。
  2. 6桁の数字を入力する。
  3. 確認のため、同じ6桁をもう一度入力する。2回が一致したらロックされる。違っていたら最初からやり直す。
- **ロック中は、歯車ボタンを押すとパスワードを求める。** 合うまで設定と記録の画面は開かない。まちがえても回数制限はない。やめるとゲームに戻る。
- **OFFにするとき**は、設定画面の中でボタンを押すだけ（画面を開けている時点でパスワードを知っているため）。
- **パスワードを忘れた場合の復旧手段は用意しない。** 名前選びの画面の「消す」でその人を消し、作り直す。
- パスワード入力は専用の数字ボタン（3列×4段）で行う。キーボードの数字キー・Backspace・Escでも操作できる。

## 理由

- 2回入力させるのは、打ちまちがいのまま確定して、誰も開けられなくなるのを防ぐため。復旧手段がないので、ここだけは手間をかける。
- 復旧手段を作ると、それ自体が抜け道になる。家庭内で使う道具なので、「消して作り直す」で十分とした。

## 影響・注意

- ロック中は記録表も見られない（設定と同じ画面にあるため）。子供に記録だけ見せたい場合は、画面を分ける変更が必要。
- 名前選びの「消す」はロック中でも押せる。子供が自分の記録ごと消すことはできてしまう。
- パスワードはブラウザの保存データにそのままの形で入っている（→ 0005 の `lock`）。開発者ツールを使える人には読める。子供のいたずら防止が目的で、強い保護ではない。
