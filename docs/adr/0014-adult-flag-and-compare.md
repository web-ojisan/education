# 0014 「おとな」の印と、くらべる画面

- 状態：採用
- 日付：2026-11-19

## 状況

子供に「パパ・ママと競う」体験をさせたい。親が同じゲームで遊んだ記録と、子供の記録を並べて見られるようにし、勝ったことがその場で分かるようにする。

## 決定

- **遊ぶ人ごとに「こども／おとな」の印を持つ。** 名前を追加する時のチェックと、設定の「おうちの人」タブで切り替える。名前えらびの画面では、おとなの名前の横に「おとな」と出す。
- **遊ぶ人の上限を3人から5人にする。** 子供2人と両親、のような組み合わせでも足りるようにする。
- **設定画面に「くらべる」タブを足す。** ロック中でもパスワードなしで見られる。
  - 段ごとに、全員の「じゅんばんのベストタイム」を横に並べる。いちばん速い人に色を付ける。
  - その下に、じゅんばん合格の数、暗記のマスの数、なぐられた回数のワーストを並べる。
  - いちばん上に、こどもには「おとなに勝っている段：3 / 9」、おとなには「こどもに負けている段：3 / 9」と出す。両方に記録がある段だけを数える。
- **じゅんばんで段を全問正解した時、成績の下に、ほかの人とくらべた一言を出す。** 相手は、その段のベストタイムがいちばん速い「ほかの人」。
  - 勝った時：「パパに勝った！（9.8秒）」
  - 届かなかった時：「パパまで あと0.6秒」
- **ハンデは付けない。** おとなもこどもも、同じ問題・同じ基準で記録する。

## 理由

- くらべる物差しを「じゅんばんのベストタイム」にしたのは、段ごとに1つの数字で、誰が速いかがすぐ分かるため。暗記の表はマスごとの状態なので、勝ち負けにしにくい。
- 成績の直後に一言を出すと、設定画面を開かなくても、遊んでいる最中に「あと少しで勝てる」「勝った」が伝わる。
- 「おとな」の印は、見出しの「おとなに勝っている段」を数えるためと、誰が親かを画面で分かるようにするために使う。

## 影響・注意

- くらべるのは、いま選んでいるモード（ふつう・上級者・地獄）の成績どうし。
- おとなが手かげんなしで遊ぶと、こどもが勝てる段がなかなか出ない。ハンデ（おとなのタイムに何秒か足す、など）が必要になったら、新しいADRで決める。
- 記録は端末ごとなので、同じ端末で遊んだ人どうししかくらべられない。
