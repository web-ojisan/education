# 0014 「おとな」の印と、くらべる画面

- 状態：採用
- 日付：2026-11-19

## 状況

子供に「パパ・ママと競う」体験をさせたい。親が同じゲームで遊んだ記録と、子供の記録を並べて見られるようにし、勝ったことがその場で分かるようにする。

## 決定

- **遊ぶ人ごとに「こども／おとな」の印を持つ。** 名前を追加する時のチェックと、設定の「おうちの人」タブで切り替える。名前えらびの画面では、おとなの名前の横に「おとな」と出す。
- **遊ぶ人の上限を3人から5人にする。** 子供2人と両親、のような組み合わせでも足りるようにする。
- **設定画面に「くらべる」タブを足す。** ロック中でもパスワードなしで見られる。
  - 段ごとに、全員の「じゅんばんのベストタイム」を横に並べる。いちばん速い人に色を付ける。
  - その下に、じゅんばん合格の数、暗記のマスの数、なぐられた回数のワーストを並べる。
  - いちばん上に、こどもには「おとなに勝っている段：3 / 9」、おとなには「こどもに負けている段：3 / 9」と出す。両方に記録がある段だけを数える。
- **じゅんばんで段を全問正解した時、成績の下に、ほかの人とくらべた一言を出す。** 相手は、その段のベストタイムがいちばん速い「ほかの人」。
  - 勝った時：「パパに勝った！（9.8秒）」
  - 届かなかった時：「パパまで あと0.6秒」
- **おとなにはハンデを付ける。** こどもとくらべる時だけ、おとなのベストタイムに「1問につき何秒」を足す（記録そのものは変えない）。おとなどうし、こどもどうしをくらべる時は足さない。
- **ハンデは1問につき＋2秒から始まり、こどもが勝つたびに0.5秒ずつへる。**
  - ハンデは「こども・相手のおとな・モード・段」の組み合わせごとに持つ。3の段でパパに勝つと、その子に対するパパの3の段のハンデだけがへる。
  - ＋2.0 → ＋1.5 → ＋1.0 → ＋0.5 → なし。同じ段で4回勝つとハンデなしになる。
  - ハンデなしで勝つと「ハンデなしで勝った」として、くらべる画面に王冠が付く。
  - 進み具合は、こどもの側に保存する（`hc`）。「記録を消す」で消える。
- **ハンデがへった時は、演出で知らせる。**
  1. 成績の表示で、まず明るく祝う：「おめでとう！ パパに勝った！（ハンデこみ 18.5秒）」とファンファーレ、紙ふぶき。
  2. そのあと暗転し、不気味な音（うなる低音、鼓動、雷）とともに、赤い文字がゆっくり浮かぶ：「パパの力が 解放された……！」「パパのハンデ ＋2.0秒 → ＋1.5秒」。約3.6秒。画面を押すと飛ばせる。
  3. 文言はへるほど強くなる：「さらに解放された……！」→「目をさました……！！」→「本気を出した……！！！」（ハンデなしになった時）。
  4. ハンデなしで勝った時は、こわい演出ではなく、金色の画面と王冠で「ハンデなしで パパに勝った！ ほんとうの勝ち！」と祝う。
  5. 一度に何人かのおとなに勝った時は、「パパとママの…」とまとめて1回出す。
- くらべる画面のおとなの数字は、ハンデを足した後のもの。その下に、いまのハンデ（「ハンデ +1.5」）を出す。おとなが見ている時は、最初のこどもに対するハンデで表示する。

## 理由

- くらべる物差しを「じゅんばんのベストタイム」にしたのは、段ごとに1つの数字で、誰が速いかがすぐ分かるため。暗記の表はマスごとの状態なので、勝ち負けにしにくい。
- 成績の直後に一言を出すと、設定画面を開かなくても、遊んでいる最中に「あと少しで勝てる」「勝った」が伝わる。
- 「おとな」の印は、見出しの「おとなに勝っている段」を数えるためと、誰が親かを画面で分かるようにするために使う。

## 影響・注意

- くらべるのは、いま選んでいるモード（ふつう・上級者・地獄）の成績どうし。
- ハンデの大きさと、1回でへる量は、コード内の `ADULT_HANDICAP`・`HC_STEP`（ミリ秒）で決めている。
- おとなの絵はないので、演出は文字・光・音で作っている。子供がこわがりすぎる場合は、音と暗さを弱める。
- 記録は端末ごとなので、同じ端末で遊んだ人どうししかくらべられない。
