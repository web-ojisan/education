# 0016 1サイクルの長さ

- 状態：採用（0002 の「1サイクル」と弱点タイプの選び方、0005 のワースト記録の条件を置き換える）
- 日付：2026-11-24

## 状況

全部の段を有効にすると、1サイクルは敵9人・81問で、5〜6分かかる。毎回これだときつい時がある。復習では、にがてな問題を織り交ぜて半分くらいで終わらせたい。段を減らせば短くはなるが、それでは全体から織り交ぜる復習にならない。

## 決定

- **設定の「あそびかた」に「1サイクルの長さ」を足す。** こたえを打つ・おんどくの両方に効く。

| 長さ | 敵の数 | 全部の段が有効な時 |
|---|---|---|
| ぜんぶ | えらんだ段の数 | 敵9人・81問 |
| はんぶん | えらんだ段の数の半分（切り上げ） | 敵5人・45問 |
| みじかめ | 3人（えらんだ段が3より少なければその数） | 敵3人・27問 |

- **つづきは次のサイクルで出る。**
  - じゅんばん・おんどく：「次はどの段か」を保存する（`pos`）。日をまたいでも、名前を選び直しても、続きの段から始まる。出題にかかわる設定を変えた時は、最初の段に戻す。
  - ランダム：全問題をまぜた山から順に配る。山を使い切るまで同じ問題は出ないので、「はんぶん」なら2サイクルで全問を回る。山は遊んでいる間だけ持ち、名前を選び直すとまぜ直す。
- **弱点タイプは、にがてな問題を必ず入れる。** サイクルの最初に、そのサイクルで出す問題をまとめて決める。
  1. 「まちがえた」のマスを全部入れる。
  2. 「考えてる」のマスを、おそい順に入れる。
  3. 残りの枠を、ほかの問題からまぜて埋める。
  4. 全体をまぜて、敵ごとに配る。同じサイクルの中で同じ問題は出ない（出し直しを除く）。
- **なぐられた回数のワーストは、長さ「ぜんぶ」の時だけ記録する。** ほかの長さでは、今回の回数は見せるが、ワーストとはくらべない。

## 理由

- 「モード」を増やすより、長さを別の設定にした方が、ゲームタイプ（じゅんばん・ランダム・弱点）と自由に組み合わせられる。「弱点 ＋ はんぶん」が、にがてを織り交ぜた短い復習になる。
- これまでの弱点タイプは、にがてな問題が「出やすい」だけの抽選だった。短くすると、にがてな問題が1つも出ないサイクルがありえた。
- じゅんばんの続きを保存しないと、短い長さだけで遊ぶ子が後ろの段にたどり着けない。
- ワーストは、全部を回りきった時の記録にする。短い回ほど殴られる回数が少なくなり、くらべられないため。全部を回って殴られた数は「名誉の負傷」として残す。

## 影響・注意

- 「ぜんぶ」でも、続きの段から始まる。途中でやめた次の回は、その段から数えて1サイクルになる。
- ランダムの山は保存しないので、日をまたぐと最初からまぜ直す。
