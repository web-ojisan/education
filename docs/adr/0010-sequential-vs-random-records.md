# 0010 じゅんばんの記録とばらばらの記録を分ける

- 状態：採用（0004・0005 の「暗記」の判定のうち、じゅんばんの扱いを置き換える）
- 日付：2026-11-17

## 状況

じゅんばんタイプは、答えが 3、6、9…と並ぶので、九九を覚えていなくても足し算で速く答えられる。これを「暗記」に数えると、表がすぐに埋まり、モードも簡単に解放されてしまう。一方で、じゅんばんで速く言えるようになることも練習の大事な一歩なので、何も残らないのは避けたい。

## 決定

- **「暗記」の判定は、ばらばらに出た問題だけで行う。** 九九の表（マスごとの記録）に書き込むのは、ランダムと弱点で出た問題だけ。モードの解放もこの表で判定する。
- **じゅんばん（ふつうの形）で答えた問題は、九九の表には書き込まない。** 正解もまちがいも入れない。速く正解したときの判定の言葉は「暗記！」ではなく「はやい！」にする。
- **じゅんばんには、段ごとの成績を別に持つ。**
  - **じゅんばん合格**：1つの段を全問正解し、どの問題も「暗記とみなす速さ」より速かったときにもらえる。一度もらったら消えない（「記録を消す」を除く）。
  - **ベストタイム**：1つの段を全問正解したときの、答えるのにかかった時間の合計のいちばん速い記録。演出やカウントダウンの時間は含めない。
  - まちがいがあった回、記録なしの問題（30秒超・途中で止めた問題）を含む回は、タイムも合格も付かない。
- **成績はKOの直後に見せる。** 「3の段　9.8秒」と、その下に「じゅんばん合格！」「ベストこうしん！」「ベスト 9.2秒」のどれかを出す。まちがいがあった回は「まちがい 2回」と出す。このときは一呼吸（0.8秒）の代わりに約1.7秒見せる。合格したときは音と紙ふぶきを足す。
- **設定と記録の画面に「段ごとの合格」を出す。** 段ごとに、じゅんばん合格のスタンプ、ベストタイム、暗記のスタンプ（その段のマスがぜんぶ暗記になると付く。「暗記 7/9」のように進み具合も出す）を並べる。
- **穴あき・まぜる**は、じゅんばんタイプでも段の中をばらばらに出しているので、ばらばら扱いにする（まぜるの中のふつうの問題は九九の表へ、穴あきは穴あきの表へ）。段ごとの成績は付けない。
- 成績はモードごとに分けて持つ（上級者の3の段は14問なので、ふつうの3の段とは別の記録）。
- **この変更より前の記録は消す。** 九九の表は順番とばらばらが混ざっていて区別できないため、表と、それで解放したモードを一度だけ消して数え直す。穴あきの記録とワースト記録は残す。保存データに版数（`v: 3`）を持たせ、版数が古いときにこの処理を行う。

## 理由

- 順番に言えることと、ばらばらに聞かれて答えられることは別の力。表を分けると、「順番はできた、次はランダム」という道筋が段ごとに見える。
- 学校の九九の練習も、順番に唱える段階と、ばらばらに答える段階を分けている。
- じゅんばんのまちがいを九九の表に入れないのは、表を「ばらばらに聞かれたときの実力」だけにそろえるため。

## 影響・注意

- じゅんばんだけで遊んでいる間は、九九の表は埋まらず、モードも解放されない。
- じゅんばんでまちがえた問題は、弱点タイプの出やすさには反映されない。
- 「暗記」のスタンプは表の今の状態から毎回計算するので、遅く答えたりまちがえたりすると外れることがある。
- 「下がり九九」（9から逆順）のタイプとスタンプは、今回は入れない。
