# 0015 おんどく（暗唱テストの練習）

- 状態：採用
- 日付：2026-11-19

## 状況

学校では九九を声に出してとなえる暗唱テストがある。その練習をゲームの中でしたい、という要望があった。

音声認識で聞き取って判定する案は見送った。九九独特の読み方（ににんがし、さざんがく、はっぱろくじゅうし…）は会話用の音声認識が苦手で、正しく言ったのに不正解になるおそれが大きい。結果が返るまでの遅れで速さも測りにくく、ゲームの音がマイクに入り、子供の声が外部のサーバーに送られる、という問題もある。

## 決定

- **あそびかたを2つにする。** 設定の「あそびかた」で選ぶ。
  - こたえを打つ：これまでのゲーム。
  - おんどく：声に出してとなえる、暗唱テストの練習。
- **おんどくの進め方**
  - 敵ひとりが1つの段（1〜9の段だけ）。9つの式を、えらんだ順でとなえる。
  - 1つとなえるたびに「言えた！」を押す。押すとパンチが出て、下の欄に正しい読み方（「さんし じゅうに（3×4=12）」）が出る。合っていたかは、本人かおうちの人がたしかめる。
  - 言いまちがえた時は「まちがえた」を押す。殴られて、正しい読み方が出て、次へ進む。
  - 9つとなえ終えると、敵をKOする。
- **設定**
  - となえる順：上がり（×1→×9）／下がり（×9→×1）／ばらばら
  - 画面に出すもの：式とよみがな（「3 × 4」「さんし…」）／式だけ／なにも出さない（何番目かだけ）
  - 合格タイム：1つの段を何秒以内でとなえるか（初期値20秒、8〜40秒）
- **成績**
  - まちがいなしでとなえ終えた時の合計タイムを、段ごと・となえる順ごとに、ベストとして残す。
  - 合格タイムより速ければ「合格」。KOの後に「3の段 おんどく 12.4秒／合格！」と出す。
  - 設定の「きろく」に「おんどく」の表を足す（段 × 上がり・下がり・ばらばら）。合格した所は黄色。
- **おんどくの成績は、九九の表（暗記）、じゅんばんの成績、おとなとの勝負とは別にする。** モードの解放にも数えない。
- **判定は人がする。** 機械は、時間を測ることと、正しい読み方を見せることだけをする。
- 九九の読み方（81通り）は、コード内の `YOMI` に持つ。

## 理由

- 学校の暗唱テストは「順にとなえて、時間内に言えるか」を見る。同じ形にすれば、そのまま練習になる。
- 人が判定すれば、聞きまちがいが起きない。押した直後に正しい読み方が出るので、ひとりで遊んでいても自分でたしかめられる。
- 1つ言うたびにパンチが出るので、ふつうのゲームと同じ手ごたえが残る。

## 影響・注意

- 言っていなくても「言えた！」を押せば進む。正しくとなえたかは、本人とおうちの人にまかせている。
- タイムには、ボタンを押す時間も入る。学校で測る時間より少し長めに出る。
- 上級者・地獄（11〜19）には、おんどくはない。
- お手本を声で読み上げる機能（端末の読み上げを使う）は、今回は入れていない。
