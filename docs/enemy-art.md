# 敵キャラの絵の作り方（画像生成AI向け）

九九パンチの敵の絵を、Gemini などの画像生成AIで作るときの仕様と指示文です。
生成した画像は加工前のまま `art/raw/` に置けば、切り分け・背景の除去・軽量化はあとでまとめて行います。

## キャラ作りの方針

- **どの敵も、体はしっかり描く。** ひょろひょろの「ざこ」に見えると、倒しても気持ちよくなく、子供が飽きる。倒しがいのある相手にする。
- **弱さ・強さは、顔と小物で出す。** 序盤の敵は困り眉や不安そうな目、後半の敵は不敵な笑みや鋭い目つき、というように差をつける。
- **強さの段階は、迫力で出す。** 後半の敵ほど体を大きく、色を濃く、角・牙・よろい・炎などの小物を派手にする。
- **人間以外も出す。** 動物、ロボット、怪物など。二本足で立ち、上半身がこちらを向いている形にそろえると、人間の敵と同じ演出が使える。
- **攻撃はキャラに合わせる。** パンチに限らない（つめ、ロケットパンチ、火など）。どれも「こちらに向かって飛んでくる・迫ってくる」絵にする。
- **こわすぎない。** 子供向け。血や生々しい傷は描かない。

## 画像の仕様

- **1キャラにつき1枚のシート**。正方形の画像を2×2に区切り、同じキャラの4ポーズを並べる。
- **4ポーズ**（左上 → 右上 → 左下 → 右下）
  1. **構え**：戦う構えで、こちらを見ている。
  2. **やられ顔**：顔を殴られた瞬間。目をつぶり、口が開き、頭が少し傾く。
  3. **KO**：目が×か渦巻きで、力が抜けている。
  4. **攻撃**：こちら（画面の手前）に向かって攻撃している。拳・つめ・炎などが手前に大きく見える。
- **構図**：正面向き、腰（胴体のまんなか）から上。4ポーズとも同じ大きさ・同じ位置。体の下端はマスの下端で切れてよい。
- **背景**：マゼンタ（#FF00FF）の単色。影・地面・模様・集中線・星・文字・枠線は入れない。
- **キャラクターの色**：マゼンタ・ピンク・赤紫は使わない（背景と一緒に抜けてしまうため）。
- **絵柄**：太い黒の輪郭線、はっきりした色、少年漫画とカートゥーンの中間。
- **ファイル名**：`art/raw/<名前>.jpg` または `.png`（例：`art/raw/weak-boxer.jpg`）

## 共通の指示文

`【キャラ】` と `【攻撃】` の2か所を、下の一覧から差し替えて使います。

```
ゲーム用のキャラクターシートを1枚作ってください。

【キャラ】（ここに一覧の「キャラ」を入れる）

・正方形の画像を2×2の4マスに区切り、同じキャラクターの4つのポーズを描く。
  左上：戦う構えで、こちらを見ている。
  右上：顔を殴られた瞬間。目をぎゅっとつぶり、口が開き、頭が少し傾いている。
  左下：ノックアウトされた顔。目が×印で、力が抜けている。
  右下：【攻撃】（ここに一覧の「攻撃」を入れる）
・4マスとも同じキャラクター、同じ見た目、同じ色、同じ大きさ、同じ位置。
・二本足で立ち、正面向き、腰から上。体の下はマスの下端で切れてよい。
・体つきはしっかり、たくましく描く。弱そう・強そうの差は、表情と小物で出す。
・絵柄は、太い黒の輪郭線とはっきりした色のカートゥーン調。子供向けで怖すぎない。血は描かない。
・背景は完全にマゼンタ（#FF00FF）一色だけ。集中線、効果線、星、火花、汗、文字、影、地面、網点、グラデーション、枠線は描かない。
・キャラクターにマゼンタ、ピンク、赤紫は使わない。
```

うまくいかないとき：

- **ポーズごとに別のキャラになる**：左上（構え）だけ先に作り、その画像を添えて「このキャラクターのまま、同じ絵柄で残りの3ポーズを」と頼む。
- **背景に集中線や星が入る**：「背景は何も描かない。マゼンタの単色だけ」と重ねて伝える。少しなら切り分けの道具で取りのぞける。
- **横長・縦長で出てくる**：「画像は正方形（1:1）で」と伝える。

## ゲームへの組み込み

シートを `art/raw/<名前>.jpg`（または `.png`）に置き、切り分けの道具を実行します。4ポーズに切り分け、マゼンタの背景・集中線・星などの飾りを取りのぞいて、背景が透明な画像にします（→ [ADR 0007](adr/0007-enemy-images.md)）。

```bash
python3 -I tools/cut-enemy-sheet.py art/raw/weak-boxer.jpg public/img/enemies/weak-boxer 640
```

（Python と、`pillow`・`numpy`・`scipy` が必要です。）

できあがるファイル：

```
public/img/enemies/<名前>/idle.webp    構え
public/img/enemies/<名前>/hit.webp     殴られ顔
public/img/enemies/<名前>/ko.webp      KO
public/img/enemies/<名前>/attack.webp  攻撃
```

そのうえで `public/index.html` の敵の一覧（`ENEMIES`）に `img: '<名前>'` を書き足すと、その敵が画像で表示されます。

### 切り分けの道具がしていること・苦手なこと

- マゼンタ系の色（濃淡や網点も含む）を背景として抜きます。**キャラクターの服や体にマゼンタ・ピンク紫を使うと、そこも抜けてしまいます。**
- 細い線（集中線）と、キャラクターから離れた飾り（星、汗、文字）は取りのぞきます。**キャラクターにくっついた飾り（ほおの横の火花など）は残ります。**
- 4ポーズは同じ縮尺のまま出力します。ポーズごとにキャラクターの大きさが違うシートは、ゲームでも大きさが違って見えます。

## 注意

- **既存のキャラクターや実在の人物は、そのまま描かせない。** このサイトは誰でも見られる形で公開しているため、ネットで流行しているキャラクターや有名人に似せた絵は、権利や肖像の問題になりえます。「〜のような雰囲気の、オリジナルのキャラ」として作ります。
- 攻撃の絵があるキャラは、誤答のときにその絵へ切り替わって手前に迫ります。ドラゴンの炎やロボットのロケットパンチも、絵の中に描いてあれば、そのまま演出になります。画面全体を炎でおおうなどの追加の演出は、必要になったら別に作ります。
